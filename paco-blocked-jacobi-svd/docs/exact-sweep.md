# 每个 sweep 的配对次数

一个全局 sweep 内，块之间按 round-robin 配对，每一对块恰好相遇一次。
第 0 个块轮次中的每个块对做完整的 `2b` 元素 circle 调度，覆盖两个
块内部各一次以及这两个块之间各一次。之后每个块轮次只做二部配对：
一半固定，另一半循环移动，经过 `b` 轮覆盖该块对的全部 `b²` 跨块对。
因此每个行对恰好有一次 pivot 机会；低于阈值的 pivot 使用单位旋转。
不完整的块包含补零行，计数结论同样适用于原始行。实现对行执行 `B=QA`，
与转置表示下的列对相对应。

4096 行、block64 时共有 64 个块、63 个块轮次，每个 sweep 包含
4096×4095/2 = 8,386,560 个原始行对。旧实现对每个块对都执行完整局部
circle 调度，所以同块行对每轮 sweep 被访问 63 次，跨块行对访问 1 次，
共 16,386,048 次 pivot 机会。旧版与新版的 sweep 数含义不同。

AIV 在 UB 中计算角度、更新小 Gram 和累积旋转 R；AIC Cube 计算 Gram
和完整面板旋转 `R X`。一次完整 SVD 仍只启动一次混合核，全部 sweep、
收敛控制、预处理和后处理在 device 侧。CLI 的 `--local-sweeps` 仅接受 1。

## 验证与测量

2026-11-17 在 server 的 Ascend 910B3，CANN 8.2.RC1 上运行，block64、
batch1、FP32 epsilon 阈值、4096×4096 随机输入，种子 20261116，输入
SHA256 为 `8485da69127c68fe91b3a84082c00b678f9a1842f83d4f6aff366c66df49867d`。
四次完整调用均在 25 sweep 收敛，设备时间分别为 967.163、966.515、
966.617、966.448 ms；丢弃首次后中位数为 **966.515 ms**。默认启用
40 AIV 和 20 AIC；每个块轮次 32 个参数任务，自动模式不拆分重叠组。
测量包含设备预处理、迭代、后处理，独立 CPU 校验不计入。

独立 FP64 验证：B 行正交误差 1.116e-7、Vt 正交误差 4.953e-7、
重构相对误差 2.415e-6、右奇异向量特征残差 4.902e-6；最大奇异值
绝对误差 2.176e-4。该逐对 Gram 收敛准则不证明与 GPU XGESVDJ 的
完整停止条件或精度等价。

`tests/test_sweep_schedule.py` 统计 block16/32/64 与 4096 规模的所有行对；
`tests/run_sweep.py` 对比单轮实际 NPU 输出与独立 FP64 参考，共 9 个案例，
包括 2/4/6 块、补零行、多 batch 和部分核，最大相对误差 1.331e-5。
另有通用数值 31/31、block64 数值 9/9、控制 7/7、流水回归 11/11。
日志位于 `logs/exact-sweep/`，输入和完整输出位于 server 的
`artifacts/exact-sweep-4096/`。

## 核组流水后续优化

上述 966.515 ms 基线保留。2026-11-17 实现默认核组流水后，在同一 SHA256 输入、block64、batch1、FP32 epsilon 下，完整设备时间 warm 中位数 **904.740 ms**，仍为 25 sweep 收敛，与原版输出逐位一致；相对基线缩短 **6.39%**。本次原版同机重测为 965.768 ms。每 sweep 的 DeviceBarrier 从 254 次减为 2 次，块间交接改用 GM 版本信号；初始化、收敛汇总及最终输出仍保留必要同步。完整协议、FP64 误差、15 个单 sweep 对照、故障诊断及 profiler 证据见 [core-local-pipeline.md](core-local-pipeline.md)。
